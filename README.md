1.	Введение

Проект предназначен для анализа ежедневных температур из CSV‑файла за год. Он демонстрирует применение структур данных и алгоритмов (префиксные суммы, стек, очередь, бинарное дерево поиска) на практической задаче работы с временным рядом температур. Программа позволяет загружать и обрабатывать данные из CSV файла с датами и температурами, считать средние температуры по месяцам, искать самый холодный и самый тёплый день, сортировать месяцы по средней температуре, строить бинарное дерево поиска по температурам для поиска дней с температурой выше заданного порога и выполнять сглаживание температур с помощью скользящего среднего по окну из 7 дней.

3.	Структура модулей и функций

Модуль modules/analysis.py
Содержит всю алгоритмическую логику анализа температур: загрузка данных, префиксные суммы, вычисление средних, поиск дня с максимальной и минимальной температурой, сортировки, сглаживание.
Функции:
•	load_data - загружает из CSV‑файла списки дат и температур, определяет разделитель, пропускает пустые строки и некорректные значения температуры. Возвращает два списка одинаковой длины: dates и temperatures.

•	compute_prefix_sums - считает префиксные суммы. Используется для быстрого вычисления суммы температур на произвольном отрезке.

•	get_sum_between_days - воззвращает сумму температур на отрезке от start_idx до end_idx, используя префиксные суммы.

•	parse_date - преобразует строку даты в объект date. Поддерживает несколько форматов дат (DD.MM.YYYY, YYYY-MM-DD, DD/MM/YYYY).

•	find_date_index - находит индекс заданной даты в списке dates. Для сравнения сначала извлекает целевую дату, а затем последовательно сравнивает с каждой датой из списка.

•	average_temperature_by_month - считает среднюю температуру по каждому месяцу, опираясь на префиксные суммы. Проходит по всем датам, группирует дни по (год, месяц), для каждой группы с помощью get_sum_between_days получает сумму и делит на количество дней.

•	find_min_max_temp - линейным поиском находит самый холодный и самый тёплый день. Последовательно просматривает массив температур, запоминает минимальное и максимальное значение и соответствующие даты.

•	sort_months_by_temp - сортирует месяцы по средней температуре с помощью сортировки вставками.

•	sort_pairs_by_temp - сортирует список пар (температура, дата) по температуре (сортировка вставками). Используется для красивого вывода дат из бинарного дерева поиска в порядке возрастания температуры.

•	build_temperature_tree - строит бинарное дерево поиска (BinarySearchTree).

•	smooth_with_queue - реализует скользящее среднее по окну размера, заданного переменной window_size , с помощью очереди, в нашем случае window_size = 7. При проходе по списку температур поддерживает очередь последних 7 значений (первые 6 дней остаются без изменений).

•	smooth_week_from_date - находит в списке дат индекс заданной даты, берёт 7 подряд и сглаживает их с помощью smooth_with_queue.

Модуль modules/bst.py
Содержит реализацию бинарного дерева поиска по температурам.
class BSTNode - узел дерева, хранит: temperature (ключ), список дат с этой температурой и ссылки на левое и правое поддерево.

class BinarySearchTree
Функции:
•	insert - вставляет новую пару (температура, дата) в дерево. Если такой температуры ещё нет, создаёт новый узел, если такая температура уже есть, добавляет дату в список dates текущего узла.

•	_insert_recursive - вспомогательная рекурсивная функция для вставки: спускается влево, если новая температура меньше, и вправо, если больше, пока не найдёт подходящее место.

•	find_above_threshold - возвращает список всех пар (температура, дата) с температурой строго выше заданного порога. Внутри использует рекурсивный обход дерева.

•	_find_above_recursive - рекурсивно обходит дерево: если температура узла больше порога, добавляет все даты из узла в результат и продолжает обход влево и вправо, если меньше или равна, идёт только вправо (так как в левом поддереве температуры ещё меньше).

Модуль modules/queue.py
Реализация очереди на связном списке
class Node - узел связного списка: хранит data и ссылку next на следующий узел.

class Queue
Функции: 
•	enqueue - добавляет элемент в конец очереди.

•	dequeue - удаляет элемент из начала очереди.

•	is_empty - проверяет, пуста ли очередь.

•	size - возвращает текущий размер очереди.

•	get_all_values - проходит по всем узлам и возвращает список всех значений в очереди. Используется в smooth_with_queue для вычисления среднего по окну.

•	__str__ - строковое представление очереди в виде Queue([...]) для вывода.

Модуль modules/stack.py
Простой стек на основе списка, используется для «отмены» последнего сглаживания.
class Stack
Функции:
•	push - добавляет элемент на вершину стека.

•	pop - достает элемент с вершины стека и возвращает его.

•	size - возвращает количество элементов в стеке.

•	is_empty - проверяет, пуст ли стек.

•	peek - возвращает элемент на вершине стека, не удаляя его.

•	__str__ - строковое представление стека в виде Stack([...]).

Модуль main.py
Главный модуль программы, выполняет функцию запуска: пункты 1-5 (загрузка, префиксные суммы, средние по месяцам, экстремумы, сортировка месяцев), строит дерево, а затем запускает интерактивное меню для повторных действий (пункты 6,7,8).
Функции:
•	print_week_table – создает таблицу для 7 подряд дней: номер, дата, исходная температура и, при наличии, сглаженное значение.

•	do_search_above_threshold - реализует пункт меню для поиска дней с температурой выше заданного порога. Запрашивает порог у пользователя, вызывает tree.find_above_threshold, сортирует полученные пары по температуре с помощью sort_pairs_by_temp и выводит их в читабельном виде.

•	do_smoothing - реализует пункт меню для сглаживания 7 дней подряд. Запрашивает начальную дату, использует smooth_week_from_date, сохраняет текущий список температур в стек undo_stack, заменяет выбранный отрезок на сглаженные значения и выводит таблицу результата.

•	do_undo - реализует отмену последнего сглаживания. Если есть сохранённое состояние в стеке и известен индекс начала отрезка, восстанавливает предыдущий список температур и показывает исходные значения для этих 7 дней.

•	print_interactive_menu – предлагает пользователю меню действий (6 – снова выведет дни с температурой выше заданного порога, 7 – применение сглаживания, 8 – отмена последнего действия, 0 – выход из программы) и повторяется после первого прохода по анализу.
